# Bazar el Pelado

Tienda online construida con Next.js App Router, TypeScript y Tailwind CSS.

## Desarrollo local

Requiere Node.js 20.9 o posterior.

```bash
npm install
npm run dev
```

La tienda estará disponible en <http://localhost:3000>.

## Verificación y producción

```bash
npm run lint
npm run build
npm start
```

Las imágenes y videos del catálogo se sirven desde `public/`.
